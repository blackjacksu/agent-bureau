# Live Arm B evaluation — ADR-0003 primaries (2026-11-02)

Scope: mapped arm only (`find` over real indexed graphs in Postgres), 60 corpus tasks, 2 runs. Raw-browsing Arm A with a reference agent is not run in this environment (no agent harness here), so this is **not** the full §18 A/B gate — it measures whether the map answers real questions with the right target.

| **Total** | **60** | **59 (98%)** | **46 (77%)** | |

\* Pattern hit = a returned step/template URL contains the corpus `expected_url_pattern` token. Misses are mostly plausible-but-different targets (e.g. a face-serums category instead of the exact vitamin-C product) — target-precision work, not navigation failure.

Method: compiled MCP server (`buildFromEnv`, PgStore) + issued API key, corpora in `tools/bench/corpus/{carparts,shadesoflight,paulaschoice}.json`. Embeddings: deterministic token-hash provider (1536d) — hosted embeddings are expected to raise precision further. Fixes landed during this evaluation: embedding-dimension consistency (1536), provider-aware retrieval floor, lexical token-overlap blend in node ranking.

Remaining for the full §18 gate: Arm A baseline runs with a reference agent on the same tasks (tokens/time), then the per-site accuracy-parity comparison.
